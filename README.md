# Session 29 - NLP Vectorization

## Aim
To perform text vectorization using Bag of Words, N-Grams and TF-IDF and train a Multinomial Naive Bayes model.

## Dataset
Emotions Dataset

## Methods Used
- Bag of Words (Unigrams)
- Bag of Words (Unigrams + Bigrams)
- TF-IDF Vectorization
- Multinomial Naive Bayes

## Assignment Questions
- Q1: Data Preparation
- Q2: Bag of Words
- Q3: Bag of Words + Multinomial Naive Bayes
- Q4: Understanding Vocabulary
- Q5: N-Grams with Bag of Words
- Q6: N-Grams + Model Training
- Q7: TF-IDF Vectorization
- Q8: TF-IDF + Multinomial Naive Bayes
- Q9: Comparison of Vectorizers
- Q10: Complete Vectorization Pipeline

## Output
The project compares the accuracy of Unigram BOW, Bigram BOW and TF-IDF approaches.

- Pandas
